Mesa de Soporte TI: Formulario CRUD + Reporte Operativo

Información del Proyecto

  • Categoría: Automatización y Low-Code
  • Caso de estudio: Mesa de soporte TI con CRUD
  • Periodo: 2024
  • Link: Ver Reporte en Power BI

Visión General del Proyecto

🚀 Solución integral utilizando herramientas de bajo código de Microsoft, que no solo sirve para la gestión de tickets, sino que también puede adaptarse a áreas como ventas, desempeño de equipos, seguimiento de proyectos, etc.

🛠️ ¿Qué hice?

✅ Formulario en Power Apps

  • ➕ Agregar nuevos registros: Tickets, ventas, tareas, etc.
  • ✏️ Editar registros existentes: Actualización de información en tiempo real
  • ❌ Eliminar registros: Gestión completa del ciclo de vida de datos
  • 🔄 Sincronización automática: Todo se mantiene sincronizado en SQL

📡 Integración en Tiempo Real

Utilicé Direct Query en Power BI para que los datos ingresados en el formulario se reflejen al instante en un reporte interactivo llamado "Overview of Tickets".

📊 Reporte en Power BI

  • 🚦 Estado de los registros: Abiertos, en progreso, cerrados
  • 👥 Responsables asignados: Seguimiento por usuario
  • ⏱️ Tiempos de resolución: Métricas de eficiencia

⏱️ Beneficios Clave

🤖 Automatización

Elimina la intervención manual, reduciendo errores y ahorrando tiempo

⚡ Toma de decisiones ágil

Gracias a la actualización en tiempo real de los datos

🔧 Stack Tecnológico

Power Apps

Formulario CRUD

Power BI

Dashboard interactivo

SQL Server

Base de datos

Fuente de Datos

Los datos que utilicé fueron obtenidos de Kaggle, esto garantiza que no hay problemas de confidencialidad y que los datos son 100% adaptables a las necesidades del proyecto.

Casos de Uso Adicionales

  • • Ventas: Gestión de oportunidades y pipeline comercial
  • • Equipos: Seguimiento de desempeño y KPIs del equipo
  • • Proyectos: Gestión de tareas y entregables
  • • Inventarios: Control de stock y movimientos

Esta solución demuestra el poder de las herramientas de bajo código de Microsoft para crear sistemas operativos completos, automatizados y escalables, sin necesidad de desarrollo tradicional extenso.
